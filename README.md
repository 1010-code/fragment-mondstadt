# 碎片 · 蒙德的一日（交互网页）

一个单页交互小站：点击星空 → 道路与行走小人 → 挥剑/碎片掉落 → 碎片投影文字 → 碎片收入背包 → 弹窗查看文字。
全屏黑色背景，背景音乐循环播放，状态切换均有平滑过渡，状态机 + 防抖实现。

## 文件结构

```
outputs/
├─ index.html            # 主页面（单文件，含全部样式/逻辑/内置文字兜底）
├─ preview.png           # 各状态效果预览图
└─ assets/
   ├─ bgm.mp3            # 背景音乐（已从桌面素材复制）
   ├─ 碎片文字1.txt      # 碎片文字纯文本版（页面优先读取）
   └─ 碎片文字1.docx     # 原始 Word 文档（预留实时解析接口）
```

## 运行方式

- **直接双击** `index.html`：可完整运行。背景音乐、动画、交互全部正常；
  文字使用“内置兜底”（内容与 docx 一致）。
- **本地服务器**（推荐，启用 docx/txt 实时读取）：
  ```
  python -m http.server 8765 --directory 此文件夹
  ```
  然后浏览器打开 `http://127.0.0.1:8765/index.html`。
- **拖拽读取**：无论何种方式打开，把新的 `碎片文字1.docx` 或 `.txt`
  直接拖进页面，即可即时替换文字内容（页面内置 zip + deflate 解析器，
  无需安装任何库）。

> 说明：浏览器出于安全策略，直接双击打开（file:// 协议）时不允许页面
> fetch 本地文件，因此文字会回退到内置内容；音乐与图片不受影响。

## 状态说明（点击流转）

| 状态 | 内容 | 点击 |
| --- | --- | --- |
| 0 初始 | 全黑 + 随机星点（1–3 秒一颗，0→0.6→0 透明度，1.5 秒） | 任意位置 |
| 1 道路 | 小人位置亮起圆形光芒扩散全屏 → 70% 处道路 + 循环行走小人 | 点击小人 |
| 2 碎裂 | 小人切换挥剑动作 + 💥 + 合成玻璃碎裂音效 → 碎片带震颤掉落至中央 | 点击碎片 |
| 3 投影 | 碎片向上投影半透明模糊发光文字（内容来自碎片文字） | 点击文字外空白 |
| 4 背包 | 文字淡出 → 碎片弧线飞向右上角 → 背包出现并收纳（闪烁） | 点击背包 |

## 素材替换（index.html 顶部 CONFIG）

```js
const CONFIG = {
  MUSIC_SRC:    "assets/bgm.mp3",      // 背景音乐
  TEXT_SOURCES: ["assets/碎片文字1.txt", "assets/碎片文字1.docx"], // 文字来源（按顺序）
  GLASS_SFX_SRC: "",                   // 留空=合成碎裂声；填入 assets/xxx.mp3 则播放该音效
  WALK_IMG:     "",                    // 填入 GIF/图片路径 → 替换行走小人
  ACTION_IMG:   "",                    // 填入 GIF/图片路径 → 替换第二个动作（挥剑）
  BACKPACK_IMG: ""                     // 填入图片路径 → 替换 🎒 背包图标
};
```

- 替换背景音乐：直接把新的 mp3 放到 `assets/` 并改 `MUSIC_SRC` 即可。
- 替换文字：更新 `assets/碎片文字1.txt` 或 `assets/碎片文字1.docx`（服务器模式 / 拖拽即时生效）。
- 玻璃音效：提供文件后填 `GLASS_SFX_SRC`；否则使用 Web Audio 实时合成的“碎裂”占位音效。

## 备注

- 背景音乐默认循环（loop），页面加载即尝试播放；受浏览器自动播放策略限制，
  首次点击画面时一定开始播放。
- 碎片落地后带有轻微悬浮（非剧烈抖动），如需完全静止，删除
  `#fragment-wrap.landed #fragment { animation: floaty ... }` 一行即可。
- 调试：页面暴露 `window.__dbg()` 可读取当前状态机信息（不影响使用）。
