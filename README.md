# 碎片 · 蒙德的一日（交互网页）

🔗 **在线体验：https://1010-code.github.io/fragment-mondstadt/**

一个单页交互小站：点击星空 → 道路与行走小人 → 挥剑 / 碎片掉落 → 碎片投影文字 → 碎片收入背包 → 弹窗查看文字。
全屏黑色背景，背景音乐循环播放，状态切换均有平滑过渡，使用有限状态机（FSM）+ 防抖实现。

## 仓库结构（GitHub Pages 版）

```
fragment-mondstadt/
├─ index.html      # 主页面（单文件，含全部样式/逻辑/内置文字兜底）
├─ bgm.mp3         # 背景音乐（蒙德的一日）
├─ fragment.txt    # 碎片文字纯文本版（页面优先读取）
├─ fragment.docx   # 原始 Word 文档（预留实时解析接口）
├─ preview.png     # 各状态效果预览图
└─ README.md
```

## 玩法（点击流转）

| 状态 | 内容 | 点击 |
| --- | --- | --- |
| 0 初始 | 全黑 + 随机星点（1–3 秒一颗，0→0.6→0 透明度，1.5 秒） | 任意位置 |
| 1 道路 | 小人位置亮起圆形光芒扩散全屏 → 70% 处道路 + 循环行走小人 | 点击小人 |
| 2 碎裂 | 小人切换挥剑动作 + 💥 + 玻璃碎裂音效 → 碎片带震颤掉落至中央 | 点击碎片 |
| 3 投影 | 碎片向上投影半透明模糊发光文字（内容来自碎片文字） | 点击文字外空白 |
| 4 背包 | 文字淡出 → 碎片弧线飞向右上角 → 背包出现并收纳（闪烁） | 点击背包 |

## 本地运行

- 直接双击 `index.html` 即可（file:// 下文字回退到内置内容，内容一致）。
- 本地服务器（启用 docx/txt 实时读取）：
  ```
  python -m http.server 8765
  ```
  然后访问 `http://127.0.0.1:8765/index.html`。
- 拖拽读取：把新的 `fragment.docx` / `.txt` 直接拖进页面即可即时替换文字。

## 素材替换（index.html 顶部 CONFIG）

```js
const CONFIG = {
  MUSIC_SRC:    "bgm.mp3",          // 背景音乐
  TEXT_SOURCES: ["fragment.txt", "fragment.docx"], // 文字来源（按顺序）
  GLASS_SFX_SRC: "",                // 留空=合成碎裂声；填入 mp3 路径则播放该音效
  WALK_IMG:     "",                 // 填入 GIF/图片路径 → 替换行走小人
  ACTION_IMG:   "",                 // 填入 GIF/图片路径 → 替换第二个动作（挥剑）
  BACKPACK_IMG: ""                  // 填入图片路径 → 替换 🎒 背包图标
};
```

## 说明

- 背景音乐默认循环（loop），页面加载即尝试播放；受浏览器自动播放策略限制，首次点击画面时一定开始播放。
- 文字支持直接解析 `.docx`（页面内置 zip + deflate 解析器，无需任何库）。
- 碎片落地后带有轻微悬浮（非剧烈抖动），如需完全静止，删除 `#fragment-wrap.landed #fragment { animation: floaty ... }` 一行即可。
